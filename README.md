# CodeX视频壁纸

把本地 MP4 变成 Codex 桌面客户端的动态背景，搭配透明毛玻璃、可调文字颜色和多视频轮播。

**macOS · 本地视频 · Homebrew 安装 · 源码 MIT**

这是社区制作的非官方工具，与 OpenAI 无隶属关系。仅支持视频，不支持图片。

[![实际 Codex 客户端中的视频壁纸](docs/demo.gif)](https://github.com/TheRangerStar/codex-video-wallpaper/releases/download/v0.1.0/demo.mp4)

> 实际 Codex 客户端录屏，约 86 秒，项目与账号信息已遮挡。为缩短演示，录制时临时让 8 个视频每段播放约 10 秒；正常使用时仍会完整播放每段视频再切换。GIF 为短精选，点击可查看完整 MP4；素材与遮挡说明见 [演示说明](docs/demo.md)。

## 安装

仅通过 Homebrew 分发：

```sh
brew install therangerstar/tap/codex-wallpaper
codex-wallpaper
```

需要 macOS 和已安装的 Codex 桌面客户端。Homebrew 自动安装 Node.js 22 依赖；不需要官方 Codex CLI，也不修改 `codex` 命令或终端配置。

首次连接时，如果 Codex 没有开放本机调试端口，菜单会说明原因。确认当前任务已结束后输入 `R`，允许重开客户端；也可以取消，稍后再试。不会自动中断正在进行的任务。

## 怎么用

运行 `codex-wallpaper` 后自动连接本机，成功才显示绿色状态和菜单。没有视频时直接进入菜单，由你选择文件。

| 编号 | 功能 |
| --- | --- |
| 1 | 启用视频壁纸，恢复保存的列表 |
| 2 | 选择 / 更换视频，支持单选循环或多选顺序轮播 |
| 3 | 暂停 / 继续 |
| 4 | 关闭壁纸，恢复原外观 |
| 5 | 完整视频列表、缺失文件、版本、应用位置和连接详情 |
| 6 | 文字颜色、阴影、局部玻璃底色 |
| 7 | 重新连接 |
| 0 | 退出菜单，后台继续播放 |

视频只在本机读取，不上传、不复制、不转换原文件。文件被移动或删除时会提示并跳过；全部丢失也能进入菜单重新选择，原列表记录仍保留。

## 效果与行为

- 一个背景层覆盖整个窗口，切换任务或设置页继续播放。
- 左侧栏整体毛玻璃；正文、输入框、文件卡片及设置页有局部阅读底色。
- 默认暖白字，可选自动明暗、纯白、深色或自定义颜色。正文与辅助文字保留层级，光标、选区一并适配。
- 多视频按选择器返回顺序轮播，自动换段使用约 0.6 秒叠化。选择新列表会重新加载，不使用叠化。
- 视频静音；隐藏窗口时暂停，重新显示后继续。手动暂停不会被恢复显示覆盖。
- 退出菜单、关闭终端不影响后台。主动退出 Codex 后，壁纸后台也会退出；下次运行 `codex-wallpaper` 再连接。
- 稳定连接使用轻量心跳，新窗口通过事件发现；不反复扫描进程或注入整份样式。视频解码和实时模糊仍会消耗资源。

## 升级与卸载

```sh
brew update
brew upgrade codex-wallpaper
```

升级后重新运行 `codex-wallpaper`。工具会识别同一 Homebrew 包的旧后台，切换到新版本；视频列表与外观保存在固定用户目录。

卸载前在菜单输入 `4` 关闭壁纸，然后运行：

```sh
brew uninstall codex-wallpaper
```

卸载保留设置和原视频。需要清除本工具记录时，可在 Finder 的「前往文件夹」打开 `~/Library/Application Support/codex-video-wallpaper`，关闭壁纸后移除该目录。

## 兼容性与限制

最低维护基线为 **26.915.31945**，已覆盖 **26.917.51856** 的结构适配。两个版本的隔离回归、连接恢复和验证边界见 [兼容性记录](docs/compatibility.md)。这不代表所有未来版本都自动兼容；Codex 改变页面结构或调试方式时可能需要更新工具。

当前只验证过 Apple Silicon macOS。Intel Mac 的代码路径没有刻意禁用，但尚无真机验收。旧版客户端与真实电脑睡眠唤醒的复测范围也在兼容性记录中单独说明。

工具通过仅限本机回环地址的调试端口连接客户端，并核对监听进程身份，不修改安装包。调试端口可控制应用，请勿把它转发或开放到网络；正常退出客户端后从原入口重新打开即可关闭本次调试端口。

## 排查问题

- **黄色不是连接成功**：按提示等待，或确认任务结束后允许重开。绿色状态来自主窗口的新确认。
- **视频没显示**：先在菜单 `5` 查看路径和错误，再重新选择有效 MP4。MP4 是容器，能否播放也取决于内部编码。
- **文字难辨认**：菜单 `6` 选固定文字色、增加局部玻璃强度。丰富画面通常更适合固定色。
- **更新后无法使用**：重新运行命令，查看客户端版本与端口状态；提交 issue 时提供工具版本、客户端版本及错误文字。

`codex-wallpaper --version` 查看工具版本，`codex-wallpaper --help` 查看帮助。这两个命令不会启动连接。

配置和日志位于 `~/Library/Application Support/codex-video-wallpaper`。日志可能包含本地视频路径，分享前请去掉个人信息；工具不记录聊天内容。
